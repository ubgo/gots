# gots — Technical Documentation

Complete reference for the Go to TypeScript code generator.

---

## What is gots

gots reads Go source files and generates TypeScript types, enums, constants, and interfaces. It uses Go's standard `go/ast` parser for exact type extraction — no regex, no guessing.

```
Go source files → [gots] → TypeScript files
```

## CLI Commands

### `gots convert`

Convert a single Go file to TypeScript. No config file needed.

```bash
gots convert <file.go>                           # stdout
gots convert <file.go> -o output.ts              # write to file
gots convert <file.go> -s enum                   # enum style
gots convert <file.go> -s const-object           # const object style
gots convert <file.go> --emit-values             # add values arrays
gots convert <file.go> --tag yaml                # read yaml tags
gots convert <file.go> --pointers nullable       # pointer → T | null
gots convert <file.go> --empty-interface any     # interface{} → any
```

**Flags:**

| Flag | Default | Description |
|---|---|---|
| `-o, --output` | stdout | Output .ts file path |
| `-s, --style` | `union` | Output style: `union`, `enum`, `const-object` |
| `--tag` | `json` | Struct tag to read for field names |
| `--pointers` | `optional` | Pointer handling: `optional`, `nullable`, `both` |
| `--empty-interface` | `unknown` | `interface{}`/`any` mapping: `unknown`, `any` |
| `--emit-values` | `false` | Emit companion values array |

### `gots generate`

Generate TypeScript from multiple Go files using a config file.

```bash
gots generate                    # uses ./gots.yaml
gots generate -c custom.yaml    # custom config path
```

**Flags:**

| Flag | Default | Description |
|---|---|---|
| `-c, --config` | `gots.yaml` | Path to config file |

### `gots init`

Scaffold a default `gots.yaml` config file in the current directory.

```bash
gots init
```

Fails if `gots.yaml` already exists (safety check).

### `gots version`

Print the binary version.

```bash
gots version
# gots v1.0.0
```

## Configuration (gots.yaml)

### Example

```yaml
# yaml-language-server: $schema=https://raw.githubusercontent.com/khanakia/gots/main/schema.json

default_style: union
emit_values_array: false
struct_tag: json
pointer_handling: optional
empty_interface: unknown
header: "// Code generated by gots. DO NOT EDIT."

type_map:
  time.Time: string
  uuid.UUID: string
  json.RawMessage: unknown
  decimal.Decimal: string
  pq.StringArray: string[]
  net.IP: string
  sql.NullString: string | null

sources:
  - file: "pkg/constants/constants.go"
    output: "./frontend/src/types/constants.ts"
    style: const-object
    include:
      - "MessageRole"
      - "Feedback*"
    exclude:
      - "InternalThing"

  - file: "pkg/models/user.go"
    output: "./frontend/src/types/models.ts"

overrides:
  MessageRole:
    style: union
    values_array: true
  LockType:
    style: enum
  FeedbackCategory:
    style: enum
    name: FeedbackType
  User:
    fields:
      CreatedAt:
        type: Date
      password:
        skip: true
```

### All Config Options

| Key | Type | Default | Description |
|---|---|---|---|
| `default_style` | `union` \| `enum` \| `const-object` | `union` | Default output format for typed constants |
| `emit_values_array` | bool | `false` | Generate companion values array for typed constants |
| `struct_tag` | string | `json` | Which struct tag to read for field names |
| `pointer_handling` | `optional` \| `nullable` \| `both` | `optional` | How Go pointer fields map to TypeScript |
| `empty_interface` | `unknown` \| `any` | `unknown` | What `interface{}`/`any` maps to |
| `header` | string | `// Code generated by gots. DO NOT EDIT.` | Comment prepended to every generated file |
| `type_map` | map[string]string | `{time.Time: string, json.RawMessage: unknown}` | Custom Go → TypeScript type mappings |
| `sources` | array | required | Go files to parse and their output paths |
| `overrides` | map | `{}` | Per-type settings |

### Source Options

| Key | Type | Required | Description |
|---|---|---|---|
| `file` | string | yes | Path to Go source file (absolute or relative) |
| `output` | string | yes | Path for generated .ts file |
| `style` | string | no | Override `default_style` for this file |
| `include` | string[] | no | Whitelist of type names (supports `*` wildcard) |
| `exclude` | string[] | no | Blacklist of type names (supports `*` wildcard) |
| `struct_style` | `interface` \| `type` | `interface` | Struct output format |
| `embed_strategy` | `flatten` \| `extends` \| `intersection` | `extends` | Embedded struct rendering |

### Override Options

| Key | Type | Description |
|---|---|---|
| `style` | string | Override output style for this type |
| `values_array` | bool | Emit companion values array for this type |
| `name` | string | Rename the type in TypeScript output |
| `fields` | map | Per-field overrides (key = Go field name) |
| `fields.*.type` | string | Override TypeScript type for this field |
| `fields.*.skip` | bool | Exclude this field from output |

### Style Resolution Cascade

Most specific wins:

```
Per-type override  →  Source-level default  →  Global default
(overrides.Foo)       (sources[].style)        (default_style)
```

## Conversion Reference

### Typed String Constants

```go
type MessageRole string

const (
    MessageRoleUser      MessageRole = "user"
    MessageRoleAssistant MessageRole = "assistant"
    MessageRoleSystem    MessageRole = "system"
)
```

**Union (default):**
```typescript
export type MessageRole = "user" | "assistant" | "system";
```

**Enum:**
```typescript
export enum MessageRole {
  User = "user",
  Assistant = "assistant",
  System = "system",
}
```

**Const object:**
```typescript
export const MessageRole = {
  User: "user",
  Assistant: "assistant",
  System: "system",
} as const;
export type MessageRole = typeof MessageRole[keyof typeof MessageRole];
```

**Values array** (with `emit_values_array: true`):
```typescript
export const MessageRoleValues = ["user", "assistant", "system"] as const;
```

### Typed Int Constants (iota)

```go
type LockType int

const (
    _ LockType = iota
    LockReadonly
    LockUpdate
    LockDelete
)
```

```typescript
// union
export type LockType = 1 | 2 | 3;

// enum
export enum LockType {
  LockReadonly = 1,
  LockUpdate = 2,
  LockDelete = 3,
}
```

Iota values are resolved at generation time. Blank identifiers (`_`) are skipped.

### Untyped Constants

```go
const DefaultAIModelID = "openai_gpt_4"
const DefaultVectorDimensions = 768
const FeatureEnabled = true
```

```typescript
export const DefaultAIModelID = "openai_gpt_4";
export const DefaultVectorDimensions = 768;
export const FeatureEnabled = true;
```

String values get quotes, numbers and booleans don't.

### Multi-line String Constants

```go
const Instruction = `You are a helpful assistant.
You are knowledgeable.`
```

```typescript
export const Instruction = `You are a helpful assistant.
You are knowledgeable.`;
```

Go backtick strings → TypeScript template literals.

### Type Aliases

```go
type UserID int64
type Slug string
type Tags []string
type StringMap map[string]string
type IPv4 [4]byte
type Matrix3x3 [3][3]float64
```

```typescript
export type UserID = number;
export type Slug = string;
export type Tags = string[];
export type StringMap = Record<string, string>;
export type IPv4 = number[];
export type Matrix3x3 = number[][];
```

### Channel Types

```go
type EventStream chan Event
type SendOnly chan<- string
type ReceiveOnly <-chan int
```

```typescript
export type EventStream = Event;
export type SendOnly = string;
export type ReceiveOnly = number;
```

Channels extract the element type — the channel itself has no TypeScript equivalent.

### Function Types

```go
type Reducer func(accumulator, current int) int
type ErrorHandler func(err error)
type Callback func()
type Handler func(request string) (response string, err error)
type MultiReturn func(a, b int) (int, int, error)
type Comparator[T any] func(a, b T) int
```

```typescript
export type Reducer = (accumulator: number, current: number) => number;
export type ErrorHandler = (err: Error) => void;
export type Callback = () => void;
export type Handler = (request: string) => string;
export type MultiReturn = (a: number, b: number) => [number, number];
export type Comparator<T> = (a: T, b: T) => number;
```

**Conversion rules:**
- `context.Context` params are stripped
- `error` returns are stripped (TypeScript uses exceptions)
- `error` as param type → `Error` (capitalized)
- Multiple non-error returns → tuple `[T1, T2]`
- No returns / only error → `void`
- Unnamed params → `arg0`, `arg1`, ...
- Generic type params propagated

### Basic Struct

```go
// User represents a registered user.
type User struct {
    // ID is the unique identifier
    ID    int64  `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email"` // primary email
}
```

```typescript
/** User represents a registered user. */
export interface User {
  /** ID is the unique identifier */
  id: number;
  name: string;
  /** primary email */
  email: string;
}
```

Go comments become JSDoc comments in TypeScript.

### Pointer Fields

```go
type Post struct {
    Title   string  `json:"title"`
    Content *string `json:"content,omitempty"`
}
```

| Config | Output |
|---|---|
| `pointer_handling: optional` | `content?: string;` |
| `pointer_handling: nullable` | `content: string \| null;` |
| `pointer_handling: both` | `content?: string \| null;` |

### Struct Tags

Field names come from the configured struct tag (default: `json`).

```go
type Config struct {
    DatabaseURL string `json:"database_url"`  // → database_url
    Port        int    `yaml:"port"`          // → Port (no json tag)
    Password    string `json:"-"`             // → skipped
    Debug       bool                          // → Debug (no tag)
}
```

- `json:"name"` → uses `name`
- `json:"name,omitempty"` → uses `name`, comma options stripped
- `json:"-"` → field skipped entirely
- No tag → Go field name used as-is

### Embedded Structs

```go
type BaseModel struct {
    ID        int64     `json:"id"`
    CreatedAt time.Time `json:"created_at"`
}

type Article struct {
    BaseModel
    Title string `json:"title"`
}

type BlogPost struct {
    Timestamps
    SoftDelete
    ID    int64  `json:"id"`
    Title string `json:"title"`
}
```

```typescript
export interface Article extends BaseModel {
  title: string;
}

export interface BlogPost extends Timestamps, SoftDelete {
  id: number;
  title: string;
}
```

### Anonymous Inline Structs

```go
type APIResponse struct {
    Status string `json:"status"`
    Data   struct {
        User    User   `json:"user"`
        Token   string `json:"token"`
        Expires int64  `json:"expires"`
    } `json:"data"`
}
```

```typescript
export interface APIResponse {
  status: string;
  data: {
    user: User;
    token: string;
    expires: number;
  };
}
```

### Function Fields in Structs

```go
type Hooks struct {
    OnCreate func(id int64)           `json:"-"`
    OnUpdate func(id int64, data any) `json:"-"`
}
```

```typescript
export interface Hooks {
  OnCreate: (id: number) => void;
  OnUpdate: (id: number, data: unknown) => void;
}
```

Function fields with `json:"-"` are still emitted — they're callbacks, not data fields.

### Generic Structs

```go
type Box[T any] struct {
    Value T `json:"value"`
}

type Pair[K comparable, V any] struct {
    Key   K `json:"key"`
    Value V `json:"value"`
}

type NumberBox[T int | int64 | float64] struct {
    Value T `json:"value"`
}

type PaginatedResponse[T any] struct {
    Data     []T `json:"data"`
    Total    int `json:"total"`
    Page     int `json:"page"`
    PageSize int `json:"page_size"`
}

type Result[T any, E any] struct {
    Data  *T   `json:"data,omitempty"`
    Error *E   `json:"error,omitempty"`
    Ok    bool `json:"ok"`
}
```

```typescript
export interface Box<T> {
  value: T;
}

export interface Pair<K extends string | number, V> {
  key: K;
  value: V;
}

export interface NumberBox<T extends number> {
  value: T;
}

export interface PaginatedResponse<T> {
  data: T[];
  total: number;
  page: number;
  page_size: number;
}

export interface Result<T, E> {
  data?: T;
  error?: E;
  ok: boolean;
}
```

**Constraint mapping:**

| Go Constraint | TypeScript |
|---|---|
| `any` | no `extends` (unconstrained) |
| `comparable` | `extends string \| number` |
| `int \| int64 \| float64` (all numeric) | `extends number` |
| `~string` (all string) | `extends string` |

### Nested Composite Types

```go
type NestedTypes struct {
    Matrix      [][]int                      `json:"matrix"`
    SliceOfMaps []map[string]int             `json:"slice_of_maps"`
    MapOfSlices map[string][]int             `json:"map_of_slices"`
    MapOfMaps   map[string]map[string]string `json:"map_of_maps"`
    PtrToSlice  *[]string                    `json:"ptr_to_slice"`
    PtrToPtr    **int                        `json:"ptr_to_ptr"`
    SliceOfPtrs []*User                      `json:"slice_of_ptrs"`
}
```

```typescript
export interface NestedTypes {
  matrix: number[][];
  slice_of_maps: Record<string, number>[];
  map_of_slices: Record<string, number[]>;
  map_of_maps: Record<string, Record<string, string>>;
  ptr_to_slice?: string[];
  ptr_to_ptr?: number;
  slice_of_ptrs?: User[];
}
```

All nested composites are recursively resolved.

## Primitive Type Mapping

| Go Type | TypeScript |
|---|---|
| `string` | `string` |
| `bool` | `boolean` |
| `int`, `int8`, `int16`, `int32`, `int64` | `number` |
| `uint`, `uint8`, `uint16`, `uint32`, `uint64` | `number` |
| `float32`, `float64` | `number` |
| `byte` | `number` |
| `rune` | `number` |
| `uintptr` | `number` |
| `complex64`, `complex128` | `unknown` |
| `interface{}` | `unknown` (configurable) |
| `any` | `unknown` (configurable) |
| `error` | `Error` |
| `struct{}` (empty) | `void` |
| `*T` (pointer) | `T` with optional/nullable handling |
| `[]T` | `T[]` |
| `[N]T` (array) | `T[]` |
| `map[K]V` | `Record<K, V>` |
| `chan T` | `T` (element type extracted) |
| `func(...)` | `(...) => ...` |

Custom mappings via `type_map` in config override all built-in mappings.

## Include/Exclude Filtering

Patterns support `*` wildcard at the start or end.

```yaml
include:
  - "MessageRole"       # exact match
  - "Message*"          # prefix match
  - "*Status"           # suffix match

exclude:
  - "InternalThing"     # exact match
  - "*Internal"         # suffix match
```

**Logic:**
1. If `include` is non-empty, type must match at least one pattern
2. If type matches any `exclude` pattern, it's excluded
3. If no `include` list, everything is included (minus excludes)

## Prefix Stripping

Go convention prefixes constant names with the type name:

```go
type MessageRole string
const MessageRoleUser MessageRole = "user"
```

gots strips the type name prefix to produce clean TypeScript keys:

```
MessageRoleUser → "User" (stripped "MessageRole")
```

**Safety guard:** Only strips if the remainder starts with an uppercase letter. This prevents false matches:

```
"SomeOther" with prefix "S" → "omeOther" starts lowercase → keep "SomeOther"
```

## Comment Support

Go comments are preserved as JSDoc comments in TypeScript.

**Doc comments** (above the declaration):
```go
// User represents a registered user.
type User struct { ... }
```
```typescript
/** User represents a registered user. */
export interface User { ... }
```

**Inline comments** (at end of line):
```go
Email string `json:"email"` // primary email
```
```typescript
/** primary email */
email: string;
```

**Multi-line comments:**
```go
// User represents a registered user.
// It contains basic profile information.
type User struct { ... }
```
```typescript
/**
 * User represents a registered user.
 * It contains basic profile information.
 */
export interface User { ... }
```
